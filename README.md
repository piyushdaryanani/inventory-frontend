# Inventory Management System: Front End

Angular admin interface for an inventory management system: manage products, categories,
suppliers, and stock levels, with a dashboard. It talks to the REST API in
[inventory-backend](https://github.com/piyushdaryanani/inventory-backend).

## What it does
- Pages for the dashboard, products, categories, and suppliers
- Services that call the back-end API for each resource
- Form validation before anything is sent to the server

## Tech stack
Angular · TypeScript · SCSS

## Run it locally
```bash
git clone https://github.com/piyushdaryanani/inventory-frontend.git
cd inventory-frontend
npm install
npm start
```
Then open http://localhost:4200 (start the back end first).
